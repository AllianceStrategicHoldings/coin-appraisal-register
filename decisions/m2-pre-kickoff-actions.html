1 · Cloudflare R2 — create the bucket and a bucket-scoped token

Keys valid — permissions pending

What we found

The Access Key / Secret you sent are genuine — Cloudflare accepts their signature. But the token has no access to any bucket: it can't list, create, or write. It was most likely created before any bucket existed, or scoped to one we don't know about.

What to do (≈2 minutes, Cloudflare dashboard)

  1. Go to R2 → Create bucket → name it coin-appraisal-register.
  2. Go to R2 → Manage R2 API Tokens → Create API Token → permission Object Read & Write, scoped to that bucket only, no expiry.
  3. Send me the new Access Key ID and Secret Access Key.

If you already created a bucket under a different name, just tell me the name — the existing token may simply be scoped to it.

Why it matters

Every photo (lot, driver's license, items, acceptance) plus the signed offer-letter PDF and the customer signature stores here (spec 2.12). The upload flow is already built and tested in the app — this token is the only thing between "saved locally, pending" and files landing in your storage for real.

2 · CDN Greysheet — send both halves of the credential pair

Rejected by the API

What we found

Greysheet's API requires two credentials sent together on every request: an x-api-key and an x-api-token, issued as a pair under your account. You sent a single value; the API rejects it alone (tested in every combination against both of their API hosts — consistent "Forbidden").

What to do

  1. Log in at greysheet.com → account area → API Credentials.
  2. Copy both values shown there — the API key and the API token — and send them to me together.
  3. While there, confirm the subscription shows the Dealer+ tier with API access active — the wholesale-pricing endpoint requires that level.

Why it matters

This powers the wholesale price lookup on graded/collectible coins (spec 2.3) — the CDN price displayed side-by-side with your configured-margin offer, and the first link in the fallback chain (CDN → Manual Override → Ask Manager).
